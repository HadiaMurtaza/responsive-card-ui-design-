# responsive-card-ui-design-
Responsive card UI design using HTML bootstrap and CSS Grid, featuring developer profile cards and a clean, modern layout. 
## About
A responsive card UI design project created using HTML and CSS Grid.

## Features
- Responsive card layout
- Developer profile cards
- Modern design and styling
- Reusable card components

## Technologies Used
- HTML5
- CSS3
- Bootstrap

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
